# 2026-10-03: device token in SecretStorage

## Accomplished

- Device token moved from `data.json` (`tokens`) to Obsidian SecretStorage. Settings keep only `deviceTokenSecretName` (+ `legacySecretMigratedAt`). User token is memory-only, regenerated from the device token.
- Per-device migration: on load, a device whose secret storage lacks the token copies it from the legacy `tokens` entry, which is kept read-only for 60 days after the first migration, then purged. Also removed on re-pairing, secret name change, disconnect, and via the **Remove plain-text copy now** settings button.
- Default name `remarkable-synchronizer-device-token`; never overwrites a different secret (suffix `-2`, `-3`...).
- "Paired, but not on this device" state (`plugin.deviceTokenMissing`): Notice on load, status row with Connect, panel message. Never an error.
- Settings: **Device token secret** row (`SecretComponent`), plain-text copy removal row.
- `updateSettings(recipe, extraData)` writes sibling `data.json` keys in the same write (atomic name set + plaintext removal).
- Legacy desktop file import now goes into SecretStorage.

## Decisions

- Spec amendment (user): plaintext must not be deleted on first migration, or every other synced device is logged out.
- Disconnect still signs out every synced device (clears name + plaintext copy), as before.
