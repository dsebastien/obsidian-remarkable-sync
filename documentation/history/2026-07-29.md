# 2026-07-29

## Community review failure (1.8.0) — fixes

Review at community.obsidian.md failed for 1.8.0. Decision: support the latest **stable** Obsidian release, not only Catalyst (1.13.x preview).

- **Error `obsidianmd/no-unsupported-api` (blocking)**: settings tab used the declarative settings API (`getSettingDefinitions`, `getControlValue`, `setControlValue`, `update`, `refreshDomState`) — all `@since 1.13.0` (Catalyst-only) while `minAppVersion` is 1.8.7. Removed the declarative path entirely: deleted `src/app/settings/setting-definitions.ts`, `settings-tab.ts` now only has the imperative `display()`. Settings no longer appear in Obsidian's settings search (removed the claim from `docs/configuration.md`). Re-introduce the declarative API once 1.13 is the public release (see reverted commit fb7c3ee for the prior attempt).
- **Recommendation**: removed deprecated `setDynamicTooltip()` from the image-quality slider (`output-section.ts`); slider value is shown inline on recent Obsidian versions. The `display()` deprecation recommendation is unavoidable while supporting < 1.13 (non-blocking).
- **Build verification warning**: the reviewer's clean environment runs Bun 1.2.14. Two `scripts/build.ts` incompatibilities fixed and verified against a downloaded Bun 1.2.14 binary: (1) `Bun.build` `loader: { '.md': 'text' }` added — old bundlers ignore `with { type: 'text' }` import attributes and fail to resolve `CHANGELOG.md`; (2) `sourcemap: 'none'` instead of `false` (old Bun only accepts the string form).
- **Dependency advisories** (fast-uri < 3.1.3, brace-expansion < 5.0.7, all dev-transitive): bumped existing `overrides` in `package.json` to `fast-uri@3.1.4`, `brace-expansion@5.0.8`. `bun audit` clean.

## Issue #8 — automatic background sync

- New settings `autoSyncEnabled` (default false) and `autoSyncIntervalMinutes` (default 30, clamped 5–240) + "Sync" section in the settings tab (toggle + debounced slider).
- New `sync/auto-sync.service.ts`: `createAutoSyncService(deps)` with a narrow `AutoSyncDeps` surface (testable without Obsidian), plus `createAutoSyncServiceForPlugin` wiring (`window.setInterval`, `registerInterval`, pipeline, sync store). Guards: disabled / disconnected / already-running. Each run: list documents → prune orphans → sync only `needs-sync`/`never-synced` notebooks.
- Timer re-registered via `applySettings()` on load and whenever the settings change.
- Specs: `auto-sync.service.spec.ts` — clamping, scheduling, re-scheduling, guards, overlap skip, error recovery, timer callback.
